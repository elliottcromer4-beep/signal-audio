# Changelog

## 0.3.0

- Name a session folder before recording or importing audio.
- Keep original audio, mixed audio, and transcript outputs together.
- Copy imported media into its session without changing the source file.
- Show the save destination and open the session folder directly.
- Preserve name collisions and earlier transcription attempts with numbered suffixes.

## 0.2.0

- Select computer audio, microphone, or both.
- Capture both sources on a common timeline; preserve separate original tracks.
- Create a mono mixed track for transcription, including sample-rate conversion.
- Add source-specific activity indicators and remember device preferences.
- Package a portable Windows x64 build and clean GitHub source archive.
- Support transcription workers in the packaged executable.
- Add automated capture, mixing, export, and interface tests.

## 0.1.0

- Local recording and file transcription with a dark desktop interface.
- Plain text, timestamps, subtitles, and smaller AI input files.
- Transcript search, recent transcripts, text export, and saved settings.
